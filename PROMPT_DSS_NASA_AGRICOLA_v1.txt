## 1. Contexto del proyecto

Herramienta de apoyo a la decisión agrícola que combina **observaciones de la Tierra de la NASA** con datos locales de suelo, características de cultivos y prioridades del agricultor, para recomendar **estrategias de rotación de cultivos** que fortalezcan la salud del suelo y la resiliencia climática.

**Requisitos obligatorios del desafío:**
- Comparar **al menos 3 estrategias de rotación** (incluida la actual).
- Cada recomendación debe incluir: **por qué se sugirió**, **evidencia**, **beneficios**, **riesgos**, **lagunas de información**, **confianza**.
- Explicar términos científicos (evapotranspiración, NDVI, anomalía de humedad, riesgo de heladas, balance hídrico).
- Explicar diferencia entre observación satelital y medición terrestre.
- La herramienta **complementa**, no reemplaza, el criterio del agricultor.

## 3. APIs NASA actualmente consumidas (✅ YA IMPLEMENTADO)

### 3.1. NASA POWER — Daily Point
**Endpoint exacto:**
https://power.larc.nasa.gov/api/temporal/daily/point
?parameters=T2M,PRECTOTCORR,RH2M
&community=AG
&longitude=-57.48&latitude=-25.17
&start=20260901&end=20260907
&format=JSON

text
**Variables:** `T2M` (°C), `PRECTOTCORR` (mm/día), `RH2M` (%).
**Uso:** contexto meteorológico por parcela.

### 3.2. NASA CMR — Búsqueda de gránulos MODIS
**Endpoint exacto:**
https://cmr.earthdata.nasa.gov/search/granules.json
?short_name=MOD13Q1
&point=-57.48,-25.17
&temporal=2026-08-01T00:00:00Z,2026-09-23T23:59:59Z
&page_size=3

text
**Producto:** `MOD13Q1` = NDVI/EVI 16-día, 250 m.
**Uso:** capa NDVI en Leaflet.

Todas usan el mismo endpoint CMR que ya se consume para MODIS. Solo cambia short_name. La descarga del gránulo requiere token Earthdata.

5.1. 🟢 SMAP — Humedad del suelo (PRIORIDAD ALTA)
¿Por qué? Indicador directo de estrés hídrico del suelo. Decide si un cultivo sediento es viable.

Colecciones CMR (short_name):

short_name	Producto	Resolución	Frecuencia
SPL3SMP	L3 Radiometer Daily 36 km	36 km	Diario
SPL3SMP_E	L3 Enhanced 9 km	9 km	Diario
SPL4SMGP	L4 3-hourly 9 km	9 km	Cada 3 h
Request de ejemplo (idéntico al de MODIS, cambiando short_name):

text
https://cmr.earthdata.nasa.gov/search/granules.json
  ?short_name=SPL3SMP_E
  &point=-57.48,-25.17
  &temporal=2026-08-01T00:00:00Z,2026-09-23T23:59:59Z
  &page_size=10
Alternativa simplificada — AppEEARS (recomendada si no se quiere manejar HDF5):

text
POST https://appeears.earthdatacloud.nasa.gov/api/task
Authorization: Bearer <EARTHDATA_TOKEN>
Content-Type: application/json

{
  "task_type": "point",
  "task_name": "smap_parcela_001",
  "params": {
    "dates": [{ "startDate": "08-01-2026", "endDate": "09-23-2026" }],
    "layers": [{ "product": "SPL3SMP_E.006", "layer": "soil_moisture_am" }],
    "coordinates": [{ "id": "parcela_001", "latitude": -25.17, "longitude": -57.48 }],
    "output": { "format": { "type": "geotiff" }, "projection": "geographic" }
  }
}
5.2. 🟢 ECOSTRESS — Evapotranspiración y estrés de la vegetación (PRIORIDAD ALTA)
¿Por qué? Distingue entre vegetación "verde" (NDVI) y vegetación estresada por falta de agua. Mide ET real.

Colecciones CMR:

short_name	Variable
ECO3ETPTJPL	ET (PT-JPL)
ECO3ETALEXI	ET (ALEXI)
ECO3ESI	Evaporative Stress Index
ECO3WUE	Water Use Efficiency
Request CMR:

text
https://cmr.earthdata.nasa.gov/search/granules.json
  ?short_name=ECO3ETPTJPL
  &point=-57.48,-25.17
  &temporal=2026-08-01T00:00:00Z,2026-09-23T23:59:59Z
  &page_size=10
Recomendado: usar AppEEARS con layer EVAPOTRANSPIRATION_PT_JPL_ETinst.

5.3. 🟢 GPM IMERG — Precipitación de alta resolución (PRIORIDAD ALTA)
¿Por qué? POWER da precipitación diaria; IMERG da 30 min y mejor detección de eventos extremos (erosión, escorrentía).

Colecciones CMR:

short_name	Frecuencia
GPM_3IMERGHH	30 min
GPM_3IMERGDF	Diario
GPM_3IMERGDL	Diario (baja latencia)
Request CMR:

text
https://cmr.earthdata.nasa.gov/search/granules.json
  ?short_name=GPM_3IMERGDF
  &point=-57.48,-25.17
  &temporal=2026-08-01T00:00:00Z,2026-09-23T23:59:59Z
  &page_size=5
Métricas derivables: intensidad máx. diaria, días con lluvia >50 mm (riesgo erosión), racha seca (días consecutivos <1 mm).

5.4. 🟡 SRTM — Elevación y pendiente (PRIORIDAD MEDIA)
¿Por qué? Pendiente condiciona erosión, escorrentía y microclima. Necesario para RUSLE simplificado.

Colecciones CMR: SRTMGL1 (30 m), SRTMGL3 (90 m).

Alternativa sin autenticación — OpenTopography API:

text
https://portal.opentopography.org/API/globaldem
  ?demtype=SRTMGL1
  &south=-25.20&north=-25.14&west=-57.51&east=-57.45
  &outputFormat=GTiff&API_Key=<KEY>
5.5. 🟡 MODIS extendido — LST y ET (PRIORIDAD MEDIA)
Ampliar el ModisService existente con:

short_name	Variable	Uso agrícola
MOD11A2	LST 8-día	Riesgo de heladas (LST_min < 3 °C)

  &page_size=10
5.6. 🟡 Landsat 8/9 — NDVI 30 m (PRIORIDAD MEDIA)
Para parcelas pequeñas donde MODIS (250 m) es insuficiente.

text
https://cmr.earthdata.nasa.gov/search/granules.json
  ?short_name=LANDSAT_OT_L2
  &point=-57.48,-25.17
  &temporal=2026-08-01T00:00:00Z,2026-09-23T23:59:59Z
NDVI = (NIR − Red) / (NIR + Red), bandas 5 y 4.

5.7. 🔵 GRACE-FO y GEDI (OPCIONAL, no bloqueante)
GRACE-FO → tendencia multianual de agua subterránea (solo gráficos de tendencia).

GEDI → biomasa / materia orgánica (rotaciones con cobertura vegetal).

Cliente CMR unificado (base para todos los servicios nuevos)
php
// app/Services/Nasa/CmrService.php
public function searchGranules(
    string $shortName, float $lat, float $lon,
    Carbon $start, Carbon $end, int $pageSize = 10
): array {
    $response = Http::get('https://cmr.earthdata.nasa.gov/search/granules.json', [
        'short_name' => $shortName,
        'point'      => "{$lon},{$lat}",
        'temporal'   => "{$start->toIso8601ZuluString()},{$end->toIso8601ZuluString()}",
        'page_size'  => $pageSize,
    ]);
    return $response->json('feed.entry', []);
}

9. Motor de IA / Recomendador — auditoría requerida
9.1. Debe producir
≥3 estrategias (actual + 2 alternativas).

Cada una con: why_suggested, evidence, benefits, risks, information_gaps, confidence en [0,1], requires_local_validation (bool).

9.2. Entrada
observations (NASA), farmer_priorities, crops, historial de rotaciones.

9.3. Enfoque recomendado
Sistema experto basado en reglas (obligatorio como fallback).

Ejemplo: "si humedad_media_90d < percentil 15 histórico y cultivo_actual.water_demand='alto' → sugerir cultivo con drought_tolerant=true y water_demand='bajo'".

Score multiobjetivo ponderando prioridades del agricultor.

ML (opcional): RandomForest/XGBoost + SHAP para explicabilidad.

9.4. Explicabilidad obligatoria
Cada recomendación debe citar evidencia numérica, p. ej.:

"SMAP muestra humedad promedio de 0.12 m³/m³ en los últimos 90 días (percentil 15 histórico) → alto estrés hídrico."

9.5. Feedback loop
Persistir en tabla feedback y usar para re-rankear (si "no útil" ≥3 veces en misma región → bajar peso).
